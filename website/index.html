About

CN is a Computer Networks project that simulates packet delivery across a network, including routing algorithms, error control (CRC/checksum), and self-healing mechanisms that recover from link and node failures.

Features

Packet Delivery

Simulate end-to-end packet transmission across a topology of routers and links.

Routing Algorithms

Dynamic path selection and forwarding decisions through the network graph.

Error Control

CRC and checksum validation to detect and handle corrupted packets.

Self-Healing

Automatic recovery from link and node failures via rerouting.
